# Joel Portfolio MERN Starter

This project turns the original static portfolio into a basic MERN-style app with:

- Express API server
- MongoDB-ready backend configuration
- React frontend powered by Vite
- Production build support

## Scripts

- `npm install`
- `npm run dev` — starts the API and frontend together
- `npm run build` — builds the React app for production
- `npm start` — runs the Express server with the built frontend

## Environment

Copy `.env.example` to `.env` and update your MongoDB URI if needed.
